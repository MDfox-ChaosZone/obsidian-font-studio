# 字体工坊 · Font Studio

[English README](README.en.md)

为 Obsidian 的笔记、界面和白板搭配字体。可以用导入的拉丁字体显示英文，再用本机中文字体补齐汉字。每个仓库保存自己的字体库和排版预设。首次启用时沿用当前主题和 Obsidian 的字体设置。

## 安装

下载最新的插件安装包。[GitHub Releases](https://github.com/MDfox-ChaosZone/obsidian-font-studio/releases/latest)

1. 解压 `font-studio-1.1.1.zip`，把其中的 `font-studio` 文件夹放入仓库的 `.obsidian/plugins/`。使用自定义配置目录时，用该目录替换 `.obsidian`。
2. 确认插件目录直接包含 `main.js`、`manifest.json` 和 `styles.css`，在 Obsidian 中重新加载社区插件，启用 **Font Studio**。
3. 打开 **设置 → 字体工坊**，或在命令面板执行「打开字体工坊」。

## 作者示例方案

在设置页点击 **下载示例方案 → 下载并应用**。插件会从本项目的 GitHub Release 下载约 28.5 MiB 的 ZIP，校验 SHA-256，再导入字体并应用为新预设。安装或启动插件时不会自动下载。也可手动下载 Obsidian 版 ZIP，再用预设栏的「导入」打开。[作者示例字体方案](https://github.com/MDfox-ChaosZone/obsidian-font-studio/releases/tag/example-preset-v1)

## 第一次搭配中英文字体

1. 在「字体库」中批量选择 WOFF2、WOFF、TTF 或 OTF。一起导入同家族的常规、粗体和斜体文件，浏览器会按文本样式选择真实字形。相同文件按 SHA-256 去重。
2. 在「主要字体设置」的「正文字体」卡片点「选择字体」，先添加英文字体，再添加中文字体。使用上下箭头调整优先级。也可以直接填写本机字体家族名；桌面端在系统允许时列出本机字体，选择器支持搜索。
3. 拖动滑块或点击右侧数值输入字号。正文和公式默认显示实际像素，可在右侧切换百分比。正文的设置相对于 Obsidian 原生字号保存。设为 125% 时，原生 16 px 正文显示为 20 px，原生快捷键仍可调整大小。标题、代码等独立字号使用 px，行内和块级公式可独立按百分比缩放。每张卡片可以分别恢复默认字体和默认字号。
4. 当前预设会自动保存。想保留两种排版时，先在顶部预设栏点「＋ 新建」复制当前方案，再调整新方案。命令面板的「切换字体预设」可以直接切换。

## 排版对象

| 对象 | 行为 |
| --- | --- |
| 界面、正文 | 分别配置字体顺序、字号与字重；正文作用于源码、实时预览和阅读视图。 |
| 文件名、H1–H6 | 顶部文件名与每级 Markdown 标题各自设置；可仅调整其中一级。 |
| 行内代码、代码块 | 默认联动，可分别设置，保留代码语法高亮。 |
| 行内公式、块级公式 | 独立缩放；可替换 MathJax 的可样式化文字，数学符号和分式继续由 MathJax 绘制。 |
| Canvas | 独立配置文字卡片，嵌入笔记使用笔记排版。 |
| Mermaid、Emoji | 配置流程图、思维导图等可样式化的文字标签，以及用于缺字回退的 Emoji 字体。图形尺寸仍由图表渲染器决定。 |

局部和全局关系图标签由画布绘制，本版未提供独立的关系图字体设置。

## 预设与字体文件

- 导出文件保存在仓库根目录的 `Font Studio Exports/`，界面会显示完整路径及文件名。JSON 只含配置；ZIP 同时包含方案引用的已导入字体和匹配的粗斜体。系统字体以家族名保存。
- 其他仓库可从顶部预设栏的「导入」打开 JSON 或 ZIP。缺少的字体会列出，排版继续使用后续字体。补导对应文件后，原引用会自动生效。损坏的预设不会替换当前方案。
- 配置和导入字体分别保存在当前插件目录的 `data.json` 和 `fonts/`。跨设备使用时可传输 ZIP，或用自己的同步工具同步两者。
- 本版使用独立格式 `font-studio-preset` v1。与思源字体工坊的预设不互通。

## 开发与验证

使用 Node.js 24 和 pnpm。运行 `pnpm install` 安装依赖，`pnpm dev` 监听构建，`pnpm check` 运行测试、类型检查及生产构建。生产构建同时生成 `dist/font-studio-1.1.1.zip`。

Windows 已在 Obsidian 1.15.1 独立仓库验证三种笔记视图、真实中英文回退与粗斜体、可变字重、MathJax、Mermaid、Canvas、弹出窗口、原生字号联动及停用恢复。第二个仓库验证了自定义配置目录和预设迁移。移动布局、触摸排序、导入导出和重启恢复使用 Obsidian 自带的移动模拟模式验证。Android、iOS、macOS 和 Linux 尚未做实机验收。
